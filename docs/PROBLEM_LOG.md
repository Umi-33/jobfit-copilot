# V0 问题记录

## 已知取舍

1. JD 解析使用正则和关键词匹配，适合 V0 验证，不适合复杂真实招聘语料。
2. 薪资解析优先覆盖常见格式，例如 `8-12k`、`8000-12000`、`8千-12千`。
3. 技能匹配依赖关键词和别名表，后续需要用更完整的技能词库。
4. 项目推荐依赖用户画像文本中的项目关键词，暂不做简历结构化导入。
5. Mock LLM 不参与评分，避免自然语言建议反向影响规则判断。

## 后续可改进

- 增加更多城市、行业、岗位类型解析规则。
- 增加岗位类别识别，例如 AI 应用、前端、运营、销售、数据分析。
- 引入配置化规则文件，便于调参。
- 增加 FastAPI 接口。
- 增加 Vue 前端页面。
- 接入真实 LLM 前先加入事实约束和防虚构检查。
